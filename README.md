Basic Python programs demonstrating fundamental programming concepts.

 Project Description

This repository contains simple Python programs for practicing basic programming concepts. The programs use standard Python features and do not require external libraries.

## Files and Their Purpose

| File | Purpose |
|---|---|
| `factorial.py` | Takes a number from the user and calculates its factorial. |
| `fibonacci.py` | Generates Fibonacci numbers for a given number of terms. |

## Installation / Setup

Install Python on your computer.

No external libraries are required.

## Dependencies

- Python
- No external libraries

## How to Run

Open a terminal in the repository folder and run:

python factorial.py
